## 必答要点

1. URDF 用 XML 描述刚体 Link 和连接它们的 Joint；本模型是 11 links、10 joints 的单棵树。
2. `parent/child` 指定树连接；`origin xyz/rpy` 定义 child joint frame 相对 parent 的位姿；`axis` 是在 joint frame 中的运动轴；`limit` 是关节范围、速度与力矩约束。
3. 根坐标系是 `base_link`，主链为 `base_link → link0 → link1 → link2 → link3 → link4 → link5 → link6`，末端为 `grasping_frame`。
4. 课程版仅将 `joint4.axis` 从 `1 0 0` 改为 `-1 0 0`；位置和轴线不变，但同一正角度的转动方向反转。
5. 当前视觉层为 68 个基础几何体组合；移除 visual 与材质定义后，重构前后 URDF 相等，因此碰撞、惯性、TF 和运动学语义没有变化。
