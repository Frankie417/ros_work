三、设计报告
一、设计思路
1.1 任务分解与堆叠顺序
本次实验将第三章的“中央方块依次归位到四个区域”反向应用：从四个已标定区域抓取方块，再运送至中央 P4，由下至上形成四层方块塔。代码中四个来源区依次为 P0、P2、P8、P6；对应模板中的 A、B、C、D，分别堆放在第1至第4层。

1.2 安全路径与动作顺序
单块作业过程为：Home → 夹爪张开 → Pick Above（抓取上方点）→ Pick（抓取）→ 夹爪闭合 → Lift（抬升）→ Home（转移过渡）→ Place Above（放置上方点）→ Place（放置）→ 夹爪松开 → Retreat（退出）→ Home。按低层先放、高层后放的顺序操作，确保每次放置均有下层支撑。

三、ROS/程序通信与控制系统设计
3.1 控制系统总体结构
本实验采用 Python SDK，没有使用 ROS。硬件控制对象为 Arm5DoFUServo，运动学检查使用 Arm5DoFKinematic，分别承担实际动作控制与执行前可达性判断。
这样分工后，堆叠设计负责决定方块怎样移动，控制接口负责协调运动与开闭爪。机械臂不能只到达一个坐标就结束任务，还要在合适时刻夹紧、保持和释放方块。因而控制系统需要按设计顺序衔接动作，并在发现不可达目标或运行异常时阻止后续搬运，避免继续使用不明确的现场状态。
3.2 机械臂运动与夹爪动作配合
机械臂运动与夹爪开闭需要分开控制。接近前开爪，让夹爪能够包围方块；到达抓取位置后闭合，减少夹住边角的可能；搬运时保持夹持，到达放置位置后再释放。如果夹爪过早打开，方块可能尚未获得支撑；如果未到抓取点就闭合，也可能造成偏心夹持或空抓。

3.3 动作时间参数与等待机制
机械臂运动需要时间，夹爪也不能在运动尚未结束时就切换状态。第四章末端动作时长为 0.8 s，夹爪动作为 0.5 s，并使用等待设置衔接各阶段。这样可减少机械臂仍在接近方块时就闭爪，或尚未到放置点就释放的情况。软运动设置用于按 SDK 的方式平滑运动，不代表已规划直线路径。

五、控制功能开发
5.1 公共动作函数
程序将重复动作封装为 move_to() 和 pick_and_stack(arm, index)，由 index 选择对应的来源区、目标层号及相关位姿，避免给四个方块分别复制整套抓取程序。run_single_block(index) 先校验 index 范围和全部关键位姿，再建立 Arm5DoFUServo 对象，完成指定方块的抓取、转移与堆放。
5.2 分块执行与调试方式
Notebook 设置四个独立执行单元：run_single_block(0)、(1)、(2)、(3)，分别执行 P0→P4底层、P2→第2层、P8→第3层、P6→顶层。
每个单元内部动作自动完成，但完整四层的执行顺序仍由操作者按顺序启动相应 Cell，并非程序一次调用连续完成四块。每次先经抓取上方点接近、抓紧后返回上方点，经过 Home 转移，放置后再到 Place Above 并回 Home。若中间动作异常则不继续执行，避免未知姿态下强制动作。

第一轮成功率为 2/4=50%；第二轮和第三轮均为 4/4=100%。总体成功率为 10/12≈83.33%，整塔四层全部完成的轮次为 2/3。两次失败均发生在高层，但现有记录未给出失败时的 XY 偏移量、方块倾角或是否发生碰撞，因此不将具体故障形式或误差数值当作实测结论。

七、问题与解决方法
现象：首次测试中第1、2层放置正常，第3、4层失败；后续两轮四层均成功。已知失败集中在高层，尚无逐帧故障数据。
原因分析：第3层 Place Above=92.0 mm、Place=87.0 mm，退让高度差5.0 mm；第4层对应113.0 mm和112.0 mm，退让高度差仅1.0 mm。在实际机械臂存在定位误差、夹爪几何尺寸及方块位置偏差时，可能出现松爪后摩擦方块、退出扰动或高层偏斜；同时每层的 pitch/roll 和末端 XY 取值不同，均需结合现场观察排查。
修改思路：优先复核上层放置姿态和夹爪开度，确保安全净空后，再适当提高第3、4层退出上方点并复验逆运动学与避碰路径；同步检查 P4 中央基准和四区方块摆放。原始 Notebook 没有记录上述参数已经修改，因此此处列为后续优化方案，不作为本次已实施措施。
验证结果：第二、第三轮按既定顺序完成四层堆叠。要确定失败原因，仍需在控制条件一致时记录放置前后方块偏移、释放状态及高层退出动作，并对调整前后分别开展重复试验。

八、创新点说明（选写）
本次实现的改进在于位姿与动作流程分离：SOURCE_POSES、STACK_POSES 和 STACK_APPROACH_POSES 统一管理四块参数，pick_and_stack() 复用同一套动作；执行前对各关键位姿进行逆解检查，并在异常时中止后续动作。四层高度采用逐层标定的位姿表，而非自动识别和实时修正；原代码没有实现视觉闭环纠偏或失败自动重试。
九、问题与分析
机械臂完成抓取和放置动作，并不代表方块一定能够整齐堆叠。在实际操作中，还需要考虑方块位置、夹持姿态、放置高度和退出动作等因素。特别是四层堆叠时，下层的偏差可能影响上层，使整个方块塔出现错位或倾斜。

1. 四个方块叠起来不直
各层放置中心未完全对齐，下层的位置偏差会影响上层，使方块逐渐错位。
从底层开始，逐层调整放置点的 X/Y 坐标，检查方块中心是否对齐。
2. 方块放置后出现倾斜
夹爪没有夹住方块中心，或末端姿态不合适，导致方块一侧先接触下层。
调整抓取位置及 Pitch/Roll 姿态，使方块平稳接触下层后再释放。
3. 放置高度过高或过低
理论层高未考虑夹持深度、末端姿态及机械臂定位误差，导致实际放置高度不准确。
逐层微调目标 Z，避免方块下落造成偏移或挤压下层方块。
4. 夹爪张开时碰到方块
夹爪张开角度过大，释放时可能碰到已堆叠的方块，导致塔体偏移。
将释放时的开爪角度设置为 angle=0.40 rad（约22.9°），观察是否能够正常释放并避免碰撞。
5. 机械臂搬运时方块晃动
运动时间较短，姿态变化较大，方块可能在夹爪内发生相对移动。
适当延长运动时间，降低接近与放置阶段的运动速度，观察方块是否更加稳定。
