三、设计报告
一、设计思路
1. 任务阶段划分
四层方块归位分为 Approach、Pick、Lift、Transfer、Place 和 Retreat 六个阶段。机械臂先到抓取上方点，再下降抓取并闭合夹爪，随后抬升并经 Home 高位转移，到目标点上方后下降放置，最后退出并返回 Home。
Approach → Pick → 夹爪闭合 → Lift → Home → Transfer → Place → 夹爪打开 → Retreat → Home。
2. 安全高度设计依据
采用“先升高，再横移”的运动原则。
在抓取阶段，机械臂完成 Pick 后不直接进行水平转移，而是先返回对应的 Approach 位姿，使方块充分离开原来的堆叠区域，再通过 Home 高位进行中转。这样可以避免机械臂夹持方块后在较低高度横向运动时碰到剩余方块。
在放置阶段也采用类似设计。机械臂不是直接运动到低位 Place 点，而是先运动到目标点上方的 Place Above 安全位姿，再向下运动完成放置。程序中 Place Above 和 Retreat 位姿相对于 Place 位姿增加 55 mm 的高度，用于保证进入和离开目标区域时具有足够的安全距离。
3. 抓取顺序设计依据
四层方块从上到下逐层抓取，以减少上层方块对下层抓取的遮挡或干涉。放置时优先选择 P6、P8，再完成 P2、P0，使后续机械臂运动尽量避开中央 P4 堆叠区域，降低碰撞和路径干涉风险。

2. 夹爪开闭及 Pick & Place 流程
夹爪控制遵循“抓取前打开、Pick 后闭合、Place 后打开”的原则。单块方块搬运过程封装在 pick_and_place() 函数中，通过不同位姿参数重复完成四块方块的搬运。
Approach  →  Pick  →  夹爪闭合  →  Lift  →  Home  →  Transfer  →  Place  →  夹爪打开  →  Retreat  →  Home
Approach到达方块上方安全位姿
Pick下降至抓取点并闭合夹爪
Lift返回上方安全点并抬升
Transfer经 Home 高位转移
Place下降至目标位置并放置
Retreat返回上方安全点并回 Home
图2  Pick & Place 动作流程图
3. 安全路径与最低层抓取处理
机械臂运动遵循“先升高，再横移”的安全原则。抓取后先回到 Approach，再经 Home 高位转移；放置时先到 Place Above，再下降至 Place，目标上方安全点比实际放置点高 55 mm。第4层 Pick Z=13.8 mm，距离桌面最近，因此设置 MIN_PICK_Z=10.0 mm，并避免在低位直接横移。

程序利用 PICK_POSES、PICK_APPROACH_POSES 和目标位姿参数表统一管理各层参数，并通过 pick_and_place() 完成重复搬运。set_tool_pose() 返回 False 时判定当前位姿无逆运动学解并停止后续执行；START_BLOCK / END_BLOCK 用于控制执行范围。发生异常时，程序尝试打开夹爪并返回 Home，以提高调试安全性。

五、问题与解决方法
三轮测试中最明确的问题是第二轮 P0 放置偏移：第4块被搬运到 P0 后最终位置不准确，而 P6、P8、P2 均正确；第一轮和第三轮的 P0 也均正确。除此之外，最低层第4块的 Pick z=13.8 mm，是最接近桌面的抓取动作，因此仍需保留最低高度保护并避免盲目降低 Z。
针对 P0 偏移，采用“现象—原因—修改—验证”的方法：先固定其他参数，连续重复 P0 放置并记录偏移方向、距离及方块初始姿态；若多次呈现相同方向误差，再小幅修正 P0 的 x/y，必要时检查 pitch=125.0°、roll=179.2° 与夹爪释放时机。若偏移方向随机，则应优先检查方块初始摆放、夹爪是否居中和机械臂重复定位。由于第三轮 P0 已恢复正确，当前不建议仅依据第二轮一次偏移就大幅修改参数。

六、创新点说明（选写）
本实验把位姿参数统一放在 TARGETS、PICK_POSES、PICK_APPROACH_POSES 中管理，用pick_and_place()复用抓取放置动作。第 2、3 层 Roll 角度修正为 90.0°，并显式定义 4 个 Approach 位姿。DRY_RUN=True 是默认安全预览模式，只打印参数表、执行范围和预览提示，不创建机械臂对象或执行运动；真机运行须显式指定 dry_run=False。
运行前校验参数与最低抓取高度；运行时监测set_tool_pose()返回值。出错时会松爪、回到 Home 位再抛出报错。 默认DRY_RUN=True为安全预览模式，仅打印信息、不启动机械臂；真机运行需设置dry_run=False。
START_BLOCK/END_BLOCK 用来分段调试、断点续跑，防止重复搬运已经堆好的方块。 抓取抬升后先回 Home 再移动，放置前后共用同一个上方点位，避免移动时碰倒方块塔。
