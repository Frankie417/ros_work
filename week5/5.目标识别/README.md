# Ch5：基于视觉的目标识别

从现在起使用 [week5.ipynb](week5.ipynb) 逐格完成实验。Notebook 内已包含现场调参区、HSV 四色识别、离线自检、摄像头单帧探测、实时画面、截图、CSV 记录和记录统计；运行它不需要导入同目录的 `.py` 文件。

## 按顺序运行

1. 打开 `week5.ipynb`，运行参数格。相机号、ROI、面积阈值和四类 HSV 范围只在这里修改；红色保留两段区间。重启后当前设备为 `/dev/video0`，故 `CAMERA_DEVICE=0`；设备号变化时在此修改。
2. 运行识别函数格和离线自检格。离线结果只证明合成色块识别流程可运行，不能作为真机数据。
3. 运行“真实摄像头单帧探测”格。成功后会显示一帧真实画面；失败时先处理设备问题。
4. 运行“实时识别与实验取证”格，点击“启动实时画面”。单方块测试时只留一个方块在 ROI 内，移出其余三块；选中真实颜色后，使用“保存截图”和“记录一次测试”按钮。
5. 完成测试后点击“停止”，再运行最后的统计格。

截图保存在 `evidence/`；测试行追加到 `week5_test_records.csv`。记录前可填写光照、阴影、反光或背景干扰情况。建议至少取得 40 次真实测试，正确不少于 36 次。HSV 初值不能直接写成最终标定结果；报告只使用真机生成的图片、CSV 和现场记录。

当前 ROI 为 `None`，识别整幅画面；此前现场曾把 ROI 设为画面下方 `(0, 285, 640, 195)`，并根据绿色方块阴影将绿色 HSV 的 V 下限从 50 降至 35。真实调参依据和同帧截图链接记在 Notebook 的“现场取证记录”格中；固定场景的 30 帧观察不能代替 40 次单方块测试。

## 摄像头取帧超时

摄像头能打开不等于能输出画面。若单帧探测失败，在终端运行：

```bash
v4l2-ctl -d /dev/video0 --stream-mmap=3 --stream-count=3
```

本 Notebook 按第 3 章可用示例使用 `cv2.VideoCapture(CAMERA_DEVICE)`，不调用 `capture.set()`。之前版本加入宽高设置后发生取帧失败；若旧代码运行后摄像头仍无帧，先实际拔插摄像头，再重新启动 Notebook 内核并从第一格顺序运行。若系统级取帧也失败，再换 USB 接口或检查供电。设备无法取帧时，不保存截图，也不写入测试行。
