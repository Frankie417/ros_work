## 结构

新模型使用 11 个 Link、10 个 Joint，结构参考官方 Z1，但不复制官方网格：

```text
marm_z1_base_link
  └─ marm_z1_link00       底座电机壳
      └─ marm_z1_link01   肩部壳体
          └─ marm_z1_link02   长偏置承力臂
              └─ marm_z1_link03   回程臂/肘部壳
                  └─ marm_z1_link04   腕部第一模块
                      └─ marm_z1_link05   腕部第二模块
                          └─ marm_z1_link06   法兰模块
                              └─ marm_z1_gripper_stator   固定夹爪座
                                  ├─ marm_z1_gripper_mover   单侧活动夹爪
                                  └─ marm_z1_grasping_frame  末端工作坐标系
```

关键区别是末端：新模型不再使用原来的两根 `prismatic` 平行夹爪，而是采用 Z1 风格的“固定座 + 单侧转动夹爪”。固定指在右侧、活动指在左侧，零位时两指沿 X 方向左右相接；`marm_z1_gripper_joint` 是绕 Y 轴的 `revolute` 关节，范围为 `-π/2` 到 `0`。零角度为闭合方向，负角度使左侧活动指向左上方摆开。

新模型仍使用当前项目的 Graphite、Gunmetal、PearlWhite、Aluminium、OceanBlue、ElectricCyan、SafetyOrange、SignalYellow、RubberBlack 配色和 box/cylinder 基础几何体，没有引用 Unitree 的 STL/DAE。

## 展开和运行

```bash
source /opt/ros/noetic/setup.bash
source ~/arm2026_ws/devel/setup.bash

xacro ~/arm2026_ws/src/marm_description/urdf/marm_z1_style.xacro \
  > ~/arm2026_ws/generated/marm_z1_style.urdf
check_urdf ~/arm2026_ws/generated/marm_z1_style.urdf

roslaunch marm_description view_marm_z1_style.launch
```

课程版：

```bash
roslaunch marm_description view_marm_z1_style_course_variant.launch
```

RViz 固定坐标系应选择 `marm_z1_base_link`，末端坐标系是 `marm_z1_grasping_frame`。

## 当前验证结果

- XML/Xacro 展开：主版、课程版均通过。
- `check_urdf`：主版、课程版均通过。
- Link：11。
- Joint：10。
- Visual：52。
- Collision：9。
- 主版和课程版的 Xacro 差异只有 `marm_z1_joint4.axis` 的正负方向。

官方参考包位置及结构说明见 `_reference/README.md`。本独立模型只是借鉴官方 Z1 的模块化结构和夹爪概念，不声称是 Unitree Z1 的复制品，也不用于控制真实机械臂。
